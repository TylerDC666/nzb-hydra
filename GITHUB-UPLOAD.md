# Upload to your GitHub repository

1. Create `nzb-kestrel` with **Public** visibility. Do not add a license, README or .gitignore on GitHub; the latter two are already included here.
2. Extract the source ZIP and upload its contents to the repository, including `source`, `assets`, `linux`, README.md, .gitignore and .gitattributes. Do not upload the source ZIP as the only repository file.
3. Create a release tagged `v2.1.0` and titled **NZB Kestrel v2.1.0 – Windows & Linux**.
4. Attach `NZB-Kestrel-v2.1.0-Windows.zip`, `NZB-Kestrel-v2.1.0-Linux-x86_64.tar.gz` and `SHA256SUMS.txt` as release assets. The Linux archive belongs in Releases, not in the repository file-upload form.
5. Paste the supplied English release text into the release description.

No project license is granted. Dependency notices inside the Linux package apply to those dependencies only.
